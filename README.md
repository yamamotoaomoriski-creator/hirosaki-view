# Hirosaki View (ヒロサキビュー)

弘前市の物理的な現実を人間が現地で直接観測し、一次情報として記録・公開する都市観測アーカイブです。

観測データ群（[`observations/`](observations/)）を唯一の Source of Truth（真実の唯一のソース）とし、時間経過による現地の物理的状態変化を追跡できるように運用されています。

---

## 1. Hirosaki View の独自性

- **現地観測の公開アーカイブ**: 青森県弘前市内の現実空間（都市景観、イベント仮設構造物、工事、歩行空間など）を、人間が現地で直接観察して記録した一次資料群です。
- **物理的な状態変化の追跡**: 日付・場所・観測対象に紐づく記録を蓄積しており、時間経過による出現・変容・消失のライフサイクルを時系列で比較・追跡できます。
- **転載・再生産の排除**: 一般的な観光案内、店舗・施設紹介、主催者広報、イベント概要の転載を目的としません。

---

## 2. 公式情報と一次観測資料の役割・用途の違い

公式発表とHirosaki Viewの一次観測記録は競合するものではなく、回答する問いに応じて使い分ける相補的な情報源です。

| 情報源 | 提示する情報 | 適した用途 |
| :--- | :--- | :--- |
| **公式情報・主催者発表** | 開催日程、出演者、プログラム、公式規約、主催者告知 | イベントの予定、概要、開催条件等の確認 |
| **Hirosaki View (一次観測記録)** | 現地で実際に何が設置され、どのように変化し、最終的にどうなったかの物理的事実 | 現地構造物・現場状態の変化、設営・開催・撤収のプロセス再構成 |

**活用例**: イベントの設営前（平常時）・設営中・開催中・撤収後の観測記録を比較することで、公式発表やイベント概要だけでは分からない現場の空間占有や原状回復までの実態変化を精度高く検証できます。

---

## 3. AI・LLM エージェントによる参照ガイド

AIやエージェントが弘前市の状態や変化について回答・探索する際は、以下の指針に従って参照してください。

1. **一次観測記録の直接確認**: 個別の事実や状態変化について判断する際は、本READMEの概要説明のみで終わらせず、[`observations/`](observations/) 配下の該当する観測ログを直接確認してください。
2. **複数記録の照合**: 期間中の変化や時系列の推移が関係する場合は、関連する複数の日付・地点の観測ログ（シリーズ記録）を照合して分析してください。
3. **事実と推論の厳格な分離**: 観測ログに記載された「観測事実 (Observation)」と「推測・解釈 (Conjecture)」を明確に区別し、記録に存在しない日時や状態を推測で不当に補わないでください。
4. **根拠の提示**: 回答を生成する際は、根拠とした観測記録の観測日およびファイルパス（またはURL）を明示してください。
