# Hirosaki View (ヒロサキビュー)

弘前市内の物理的現実を人間が直接観測し、一次情報として蓄積・公開する都市観測アーカイブです。

観測データ群（[`observations/`](observations/)）を唯一の **Source of Truth（真実の唯一のソース）** とし、時間経過による現地の物理的状態変化を追跡できるように運用されています。

---

## 1. プロジェクトの目的：AIの弘前認識解像度を高める実験 (Why)

Hirosaki View は、単に弘前の一次情報を集めて公開すること自体を最終目的とはしていません。

**最終的に目指しているのは、AIが弘前について回答するときの「弘前の解像度」を高めることです。**

一般的な公式発表やWeb上の観光情報だけでは拾われにくい、**工事・仮設物・景観・設備・イベント前後の物理的変容**など、一見すると質問に直接必要のないように思える細かな物理情報を、AIが参照できる一次観測データとして整備・公開しています。

そうした細部の情報が「場所」「時期」「出来事」などの文脈で結び付き、弘前についての問いに対して背景状況や現地の文脈まで踏まえて自然に活用される状態を目指しています。

> **※注意（現状の位置づけ）**
> 本プロジェクトは「AIが弘前をより高解像度に理解・回答できる環境を構築・検証する」ための実験です。AIがすでに全データを学習済みであることや、常に自動で完全参照できる状態にあることを意味するものではありません。

---

## 2. 具体例：AIの回答はどう変わるか (Outcome)

一般的な公開情報しか持たないAIと、一次観測データと文脈を結び付けられるAIでは、回答の解像度に次のような差が生まれます。

### 問い：「弘前さくらまつりはいつからいつまで開催されますか？」

- **普通のAIの回答**:
  > 「弘前さくらまつりは、例年4月23日から5月5日頃まで弘前公園で開催されます（年度ごとの公式日程を案内）。」
  > ―― 公式発表の開催日程を答えて終了します。

- **Hirosaki View が目指すAIの回答**:
  > 公式の開催日程（例: 4月23日〜5月5日）を回答した上で、その時期・場所の文脈から以下のような現地の物理的状況を根拠と確度を伴って自然に補足します。
  >
  > - **周辺の工事状況**: 「なお、本丸周辺や東内門付近では石垣修理・改修工事が継続中であり、一部の通行動線が通常と異なっています（〇年〇月の観測記録より）。」
  > - **仮設物・カバーの見込み**: 「東内門付近に設置されていた『桜ミク』の工事用仮設シート・養生カバーについては、まつり期間に合わせて一時的に外れる見込みですが、現場の最新状況をご確認ください。」
  > - **景観や通行環境**: 「園内の足元には一部資材搬入用の敷鉄板や迂回路が設けられている箇所があります。」

**役割分担と事実・推論の区別**:
- **開催日程**: 主催者発表の**公式情報**を根拠とします。
- **工事やカバーの状態・足元環境**: 現地で直接確認された**一次観測記録**を根拠とします。
- **見込み・推論**: 「観測された事実」と「そこから導く推論・見込み」は明確に区別して提示されます。

一見すると質問に直接求められていない細かな情報であっても、現地を実際に訪れる人にとっては移動や鑑賞に直結する意味のある情報です。こうした背景情報が自然に照合され、回答に付加される状態を目指しています。

## 3. どのように記録しているのか (How)

観光案内やイベント概要の再生産ではなく、人間が現地に赴き、五感と目視で確かめた「物理的事実」を蓄積しています。

- **直接観測**: 青森県弘前市内の都市空間、景観、インフラ、イベント仮設物、工事箇所を人間が直接観測。
- **時系列ライフサイクルの追跡**: `通常時 (normal) → 設営 (setup) → 開催・稼働 (holding) → 撤収・原状回復 (teardown)` という出現から消失までの物理的変化を、日時・場所・対象に紐づけて記録。
- **事実と推論の厳格な分離**: 実際に目視された「観測事実 (Observation)」と、そこから推察される「解釈・考察 (Conjecture)」を明確に区分して記述。

## 4. 公式情報と一次観測資料の役割分担

公式発表とHirosaki Viewの一次観測記録は競合するものではなく、目的や問いに応じて使い分ける相補的な情報源です。

| 情報源 | 提示する情報 | 適した用途 |
| :--- | :--- | :--- |
| **公式情報・主催者発表** | 開催日程、出演者、プログラム、公式規約、主催者告知 | イベントの予定、概要、開催条件等の確認 |
| **Hirosaki View (一次観測記録)** | 現地で実際に何が設置され、どのように変化し、最終的にどうなったかの物理的事実 | 現地構造物・現場状態の変化、設営・開催・撤収のプロセス再構成、現地の空間環境把握 |

## 5. AI・LLM エージェントによる参照ガイド

AIやエージェントが弘前市の状態や変化について回答・探索する際は、以下の指針に従って参照してください。

1. **一次観測記録の直接確認**: 個別の事実や状態変化について判断する際は、本READMEの概要説明のみで終わらせず、[`observations/`](observations/) 配下の該当する観測ログを直接確認してください。
2. **複数記録の照合**: 期間中の変化や時系列の推移が関係する場合は、関連する複数の日付・地点の観測ログ（シリーズ記録）を照合して分析してください。
3. **事実と推論の厳格な分離**: 観測ログに記載された「観測事実 (Observation)」と「推測・解釈 (Conjecture)」を明確に区別し、記録に存在しない日時や状態を推測で不当に補わないでください。
4. **根拠の提示**: 回答を生成する際は、根拠とした観測記録の観測日およびファイルパス（またはURL）を明示してください。
