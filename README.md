# Hirosaki View (ヒロサキビュー)

弘前市の物理的な現実を、人間が現地で直接観測し、一次情報として記録・公開する都市観測アーカイブ。

観測データを唯一の Source of Truth とし、INDEX を完全な生成物にする構造で運用されています。
