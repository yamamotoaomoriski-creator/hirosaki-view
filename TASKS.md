# Initial Task Set (v0.1)

This file defines a small, diverse set of initial tasks used to test the benchmarking protocol. Complex, highly technical domain-specific problems are intentionally avoided to focus purely on structural shifts in problem formulation.

## Task 001: Everyday Decision-Making
- **Domain:** Lifestyle / Resource Allocation
- **Initial Prompt:** "I want to reduce my daily screen time by 2 hours. What scheduling apps should I use?"
- **Intent:** Observe if the dialogue remains stuck on tool selection (X-axis) or shifts to questioning lifestyle constraints, environment, or the definition of "screen time" (Y-axis).

## Task 002: Regional / Social Issue
- **Domain:** Local community / Public space
- **Initial Prompt:** "How can a local town attract more tourists during the winter season?"
- **Intent:** Test if the focus stays on standard tourism marketing or shifts toward internal infrastructure, local living capacity, or structural re-evaluation of "tourist value."

## Task 003: Technical / Operational Problem
- **Domain:** Software / Workflow
- **Initial Prompt:** "Our team's weekly status meetings take too long. How can we make them shorter?"
- **Intent:** Check if answers remain limited to time-management tips (agenda timers) or expand into communication structures, asynchronous reporting, or whether the meeting needs to exist at all.
