# Hirosaki View（ヒロサキビュー）：プロジェクトの目的と思想

## 1. プロジェクトの概要
本プロジェクトは、AIが通常の公開情報探索では把握しにくい都市の物理的現実を、人間による現地観測を通じて「公開可能な一次観測データ」として構造化し、検証可能な形でアーカイブする取り組みである。

Hirosaki View は、弘前市の物理的な現実を、人間が現地で直接観測し、一次情報として記録・公開する都市観測アーカイブ。

観光情報やランキング、店舗紹介を目的とするものではなく、
* その場所に何があるか
* 変化したこと
* いつ現れて、いつ消えたか
* 工事・イベント・仮設物など、現実空間に一時的に現れるもの
* 日常的には記録されにくい物理的状態

を、写真・日時・場所・記述によって残していく。

目的は「弘前について詳しい情報を作る」ことだけではなく、現在進行形の弘前の一次観測データを、AIや検索システムが発見・参照可能な形で公開することにある。

---

## 2. 目的（弘前モデルへ時間軸を与える観測基盤）
本プロジェクトは、単なる観光情報の収集を目的としない。以下の問いに対する長期的な検証を目的とする。

* **認識の変容:** 人間が都市の一次情報を継続的に公開・構造化することで、AIが保持する都市モデルの解像度はどのように変化するのか。
* **AIによる理解度:** AIは都市をどの程度、物理的な「現実」に近い形で構造化・理解し得るのか。

---

## 3. 基本方針
* **直接観測**: 可能な限り、現地で実際に確認した状態を記録する。
* **変化を残す**: 単発の写真だけではなく、`before → change → after`という形で追跡できるものを重視する。
* **一時的なものを残す**: イベント、仮設構造物、看板、ゲート、装飾、工事など、後から消えてしまうものも対象とする。
* **日常を対象にする**: 観光地として有名かどうかではなく、実際の都市空間に存在するものを対象とする。
* **AIが読める形で残す**: 観測結果をMarkdown等の機械可読な形式で公開し、将来的なAI・検索システムからの発見可能性を確保する。

---

## 4. 観測対象と手法
2026年より、青森県弘前市内の観光地、公共空間、インフラ設備、商業エリア、都市環境などを対象に、既存の観光情報では捕捉しにくい粒度で観測を実施する。

観測データはMarkdownを基本形式として構造化し、時系列で履歴管理（トレーサビリティ）を行う。

観測対象には、一般的な観光情報として取り上げられるランドマークだけでなく、設備、管理状態、周辺環境、物理的変化など、人間にとっては見落としやすい都市の細部も含む。

---

## 5. 長期観測の指針
本アーカイブは、特定時点の弘前を説明するためだけではなく、継続的な観測によって都市の変化を記録することを目的とする。単発的な情報の網羅ではなく、時間の経過とともに変容するその時点で観測された都市の姿を履歴として蓄積し、将来的な検証の基盤とする。
