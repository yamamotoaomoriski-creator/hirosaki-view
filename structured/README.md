# Structured Data

This directory is reserved for Structured Data
reconstructed from Raw Observation files according
to docs/FORMAT_MASTER.md.

## Current status

- Raw Observation files remain in observations/.
- Raw files must never be modified by reconstruction.
- Initial reconstruction is performed one file at a time.
- Generated data must be reviewed against its source
  before adoption.

This README establishes the storage location only.
It does not define the output format or initiate
reconstruction.
